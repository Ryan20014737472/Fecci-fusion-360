# Projeto FECCI — Fusion 360

Site oficial de apresentação do projeto desenvolvido para a FECCI, com foco em modelagem 3D, prototipagem e no processo de criação realizado no Autodesk Fusion 360.

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

O conteúdo do projeto ainda está em evolução. As próximas versões poderão incluir o problema investigado, a solução, a equipe, a galeria e os resultados.
